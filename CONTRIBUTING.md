# Contributing to docs-hi

Thanks for helping translate the documentation into Hindi!

## Quick start

1. Fork the repository and clone it locally.
2. Read the [style guide](terms/style-guide.md) and the [glossary](glossary/glossary.csv).
3. Pick an unclaimed page from [pages/PAGES.md](pages/PAGES.md) and claim its Linear issue.
4. Create a branch `translate/pages-XX`, translate into `pages/hi/`, and open a pull request.

## Workflow

- One page per pull request.
- Self-check before requesting review: glossary terms, spelling, no untranslated prose, formatting intact.
- Reviews: a reviewer checks technical accuracy and terminology; an approver merges.
- Reviews have a 48-hour response target so translations are never blocked.

## Terminology

Use only approved glossary terms. To propose a new term, add it to the Notion glossary with Status "Proposed" and mention it in your pull request.

## Style

Follow [terms/style-guide.md](terms/style-guide.md).
