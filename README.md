# docs-hi — Hindi Documentation Translation

Volunteer-run Hindi localization of the project documentation.

## What's here

- `pages/PAGES.md` — the 40 pages to translate, with status.
- `pages/hi/` — translated (Hindi) pages.
- `pages/en/` — source (English) pages.
- `glossary/glossary.csv` — approved English → Hindi terminology (mirrors the Notion glossary).
- `terms/style-guide.md` — Hindi style and formatting rules.
- `CONTRIBUTING.md` — how to contribute.
- `.github/` — issue and pull request templates.

## Workflow

Claim a page in Linear → translate into `pages/hi/` → self-check against the glossary → open a PR → reviewer + approver review → merge.

## Getting started

1. Read [CONTRIBUTING.md](CONTRIBUTING.md).
2. Read the [style guide](terms/style-guide.md) and the [glossary](glossary/glossary.csv).
3. Claim an unclaimed page from [pages/PAGES.md](pages/PAGES.md) and its Linear issue.
4. Open your first pull request.
